# Routine

Use `kind: routine`, description, and `uses` with [[run-usage]] for applicable
situations. Write Inputs, Do, Check, and Failure sections. Name concrete commands
and files, the evidence that proves completion, and what to do when a check fails.
Keep each routine bounded. Lessons from a run improve its instructions through
ordinary validated writes. Resolving a routine does not run commands or grant
permission. The caller executes through its existing tools and policy.

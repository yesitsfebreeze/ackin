# the zirkle host trim compiles, tests green, and measures 2.07ms inert

The cut described in [[260912-6b69]] was carried out with no compiler available, then compiled for the first time on this pass once the build signal came back ([[260912-ea92]]). It needed **no correction at all**.

- `cargo build --all-targets` rc=0, `cargo test` `53 passed; 0 failed`, in the lane worktree. `warnings = "deny"` is live (`Cargo.toml` L41-42), so zero diagnostics means zero orphaned imports and zero dead private functions after deleting three modules and splitting a fourth.
- The field rename `memory` to `reload` had been applied by exact-string match across eight files with no compiler to check it. That is the classic way to miss a site; **not one site was missed**. A `grep`-built call-site census, written down carefully, survived contact with rustc intact.
- `sdk::on_reload` (`src/sdk.rs:58`, 9 lines with its doc comment) had no caller anywhere in the tree. Deleted; the build stayed green. **It does not cascade**, and that is the finding: the `reload: Arc<Mutex<HashMap<String, Handler>>>` field it wrote to is still *read* by the dispatch arm at `sdk.rs:252` (`if host.reload.lock().contains_key("reload")`), so `dead_code` never fires even though the map can now never be non-empty. The arm is unreachable at runtime and invisible to the compiler. Anything else in this crate that is only written by a deleted API will hide the same way.
- Sweep for further dead surface, **stated at its real strength after a first draft of this note overstated it**: `src/*.rs` holds 67 `pub fn` + 26 `pub async fn` = **93 public function items** under **70 unique names**, beside 118 `pub(crate)` items and the pub types, which were not swept at all. Counting references across all of `src` is the trap — that includes `src/tests/`, so a function only a test calls reads as used. Excluding the test tree, exactly **three** production functions have no production caller: `loader.rs:917 fiber_of` (0 prod / 46 test), `sdk.rs:121 on_dispose` (0 / 2), `fiber.rs:235 retry` (0 / 1). All three were kept, on three different grounds: `retry` because the PRD forbids editing `fiber.rs` at all and a spec box pins it byte-identical; `on_dispose` because it is genuinely live — its two callers are in `src/tests/fixtures/rpc_fixture.rs`, a target declared in Cargo.toml's example table, run as a real out-of-process SDK child, and its finalizers are drained by production code at `sdk.rs:152`; `fiber_of` because rewriting 46 call sites is a test-suite redesign. **Do not call such a sweep "exhausted."** It is exhausted for one token shape, at one visibility, with the test tree excluded — say which.

**The host is genuinely inert.** Started with no profile directory at all, `zirkle daemon` logs the missing `init.lua`, logs `No path was found. about ["builtin"]`, and serves. `zirkle status` then returns exactly one fiber — `{"name":"root","uid":0,"parent":null,"inject":[],"provide":[],"state":"Active","error":null}`. No cartridge, no service, no error, and the working directory is untouched. Reproduce with `.pearde/prds/the-host-binary/probe/inert-host.sh`.

# Every cartridge.json field the capability request added is optional, so the fifteen manifests already written still read

`Cartridge` in `src/loader.rs` carries `#[serde(deny_unknown_fields)]`, so adding
`provide`, `needs`, `export` and `grant` to the document risked refusing every
manifest written before them. It does not: each new field is
`#[serde(default)]`, and an absent `grant` deserialises to `Grant::default()` —
empty in all four of `read`, `write`, `net`, `exec`, which is the tightest
policy rather than the loosest.

Measured, not assumed: all fifteen `cartridge.json` files under
`~/dev/sys/builtin` were copied into a fixture tree with stub Lua entries and
listed through the built `zirkle list`. Fifteen parsed. The one error printed
(`ui/index.ts: No such file or directory`) is the pre-existing `ui:` field
check firing on a file the fixture did not copy, not a parse regression.

The `selftest`/`integration` cross-check is guarded with
`!self.provide.is_empty()` for the same reason: `harness` declares
`selftest: "harness.selftest"` with no document-level `provide`, because its
Lua entry is what provides. Dropping the guard would refuse a real manifest.

# Pearde Dashboard

Live views over the board and the knowledge base. Needs Dataview (DQL + JS).

> Configure focus + workflow in [[WORKFLOW]]. Regenerate the board notes with `python3 resources/knowledge.py board`.

## Board — PRDs by state

```dataview
TABLE WITHOUT ID file.link AS "PRD", state, origin, priority, complexity, blast AS "blast-radius"
FROM "wiki/board"
SORT choice(state = "blocked", 0, choice(state = "open", 1, choice(state = "analyzing", 2, 3))) ASC, priority DESC
```

## Board — open work ordered the way plan.py orders it

Dependency first (unresolved needs), then priority — the three axes the scheduler reads.

```dataview
TABLE WITHOUT ID file.link AS "PRD", needs AS "Gated on", priority, complexity, blast AS "Blast"
FROM "wiki/board"
WHERE state != "done" AND state != "failed"
FLATTEN needs AS need
WHERE need.file.state != "done"
GROUP BY file.link AS PRD
SORT PRD.priority DESC
```

## Board — fed-by chains (what does this unblock)


## Board — derived lines (from → children)

## Board — footprint heatmap

Which files the touched-and-open PRDs point at — an overlap is a merge hazard.

```dataview
TABLE WITHOUT ID footprint AS "Path", length(rows) AS "Open PRDs touching it"
FROM "wiki/board"
WHERE footprint AND state != "done" AND state != "failed"
FLATTEN footprint AS footprint
GROUP BY footprint
SORT length(rows) DESC
LIMIT 20
```

## KB — most important nodes (hub ranking)

Inbound link count stands in for centrality.

```dataview
TABLE WITHOUT ID file.link AS "Node", length(file.inlinks) AS "Inlinks", length(file.outlinks) AS "Outlinks", type
FROM "wiki/conclusions" OR "wiki/sources"
WHERE length(file.inlinks) > 0
SORT length(file.inlinks) DESC
LIMIT 20
```

## KB — sources awaiting synthesis

Sources no conclusion links — candidates for the next `conclude` pass.

```dataview
TABLE WITHOUT ID file.link AS "Source", length(file.inlinks) AS "Inlinks", date
FROM "wiki/sources"
WHERE length(filter(file.inlinks, (l) => startswith(meta(l).path, "wiki/conclusions"))) = 0
SORT length(file.inlinks) DESC, date DESC
LIMIT 25
```

## KB — orphans (isolated nodes)

No links in either direction — candidates for `relink`.

```dataview
LIST
FROM "wiki/conclusions" OR "wiki/sources"
WHERE length(file.inlinks) = 0 AND length(file.outlinks) = 0
LIMIT 25
```

## KB — by focus (from WORKFLOW.md)

```dataviewjs
const wf = dv.page("wiki/WORKFLOW");
const focus = (wf?.active_focus ?? []).length ? wf.active_focus : (wf?.active_focus ? [wf.active_focus] : []);
if (!focus.length) {
  dv.paragraph("_No `active_focus` set in WORKFLOW.md — showing nothing._");
} else {
  dv.header(4, "Focus: " + focus.join(", "));
  const pages = dv.pages('"wiki/conclusions" or "wiki/sources"')
    .where(p => (p.tags ?? []).some(t => focus.includes(String(t)))
             || focus.some(f => (p.file.path ?? "").toLowerCase().includes(f.toLowerCase())));
  dv.table(["Node", "Type", "Tags", "Date"],
    pages.sort(p => p.date, "desc").limit(25)
      .map(p => [p.file.link, p.type, p.tags, p.date]));
}
```

## File index — every `@@<keyword>` and the files under it

The five File index sections fill only on the pearde repo itself — `knowledge.py index` reads `<project>/index.md` and `references/files.md`, the map this repo alone carries, so on any other board they stay empty.

One note per row of `references/files.md`, regenerated by `python3
resources/knowledge.py index`. Scroll or ⌘F a keyword to answer
`@@<something>`. The first path in a scope explains the rest.

```dataview
TABLE WITHOUT ID keyword AS "@@", length(rows) AS "n", rows.path AS "Files"
FROM "wiki/index"
FLATTEN keywords AS keyword
GROUP BY keyword
SORT keyword ASC
```

## File index — no keyword names them (the gap)

A file reachable by path only. Either some scope is missing the file, or the
file genuinely stands alone — the list is the question, not the fault.

```dataview
TABLE WITHOUT ID path AS "Path", kind, area, title AS "Is"
FROM "wiki/index"
WHERE length(keywords) = 0
SORT path ASC
```

## File index — a row naming nothing

The manifest claims a file missing from disk. `python3 resources/index.py
check` is the authority; the same defect shows here, visible while reading.

```dataview
TABLE WITHOUT ID path AS "Path", title AS "The row says"
FROM "wiki/index"
WHERE present = false
SORT path ASC
```
